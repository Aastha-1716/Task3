# Task 3 – AI Website Generation 🤖🌐

## 📌 Project Overview

This project was created as part of **Task 3: AI Website Generation**.

The objective of this task was to explore the practical use of **AI-powered tools for website development** by creating a complete website for a chosen domain. The focus was on developing a structured, functional, and visually appealing website with multiple sections rather than achieving pixel-perfect design.

The website demonstrates how AI tools can assist in transforming an idea into a working web application by helping with design, structure, components, and development.

---

## 🎯 Objective

* Explore AI-powered website generation and development.
* Create a complete website for a selected domain.
* Implement multiple structured sections and pages.
* Understand how modern AI tools can support the web development process.
* Build a responsive and user-friendly interface.

---

## ✨ Features

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aastha-1716/Task3.git
```

### 2. Navigate to the project folder

```bash
cd Task3
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The application will then be available on the local development URL displayed in the terminal.
